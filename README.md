Prima lezione - Lunedì 29 settembre 2025:
Primo approccio con il linguaggio HTML. Ho iniziato a familiarizzare con i tag di base come `<html>`, `<head>`, `<body>`, `<h1>`, `<p>`, e `<a>`. Ho creato una semplice pagina web che include un titolo, un paragrafo di testo e un link a un sito esterno.

ctrl + s per salvare il file
ctrl + a per selezionare tutto il testo
ctrl + x per tagliare il testo
ctrl + c per copiare il testo
ctrl + v per incollare il testo
ctrl + z per annullare l'ultima azione
shift + alt + f per formattare il codice

ctrl + k + c per commentare una riga o un blocco di codice
ctrl + k + u per decommentare una riga o un blocco di codice
